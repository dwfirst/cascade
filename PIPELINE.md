
4-Stage Cascade Specification


Stage 1: Semantic Deconstruction

• Target Engine: gpt-4o-mini or deepseek-chat
• Input Data: Raw, unstructured user text query.
• System Prompt:text
Role: Linguistic Analyzer / Semantic Parser.
Task: Deconstruct the following raw user text. 
Extract and isolate:
1) Core Entities (Tokens)
2) Hidden Logical Variables
3) Ultimate Intent / End Goal
Operational Constraint: Strip all emotional noise, conversational filler, and structural redundancy. 
Output: A clean, dry, structured markdown list of semantic variables.
Используйте код с осторожностью.
• Output Data: Clean tokenized semantic payload.

Stage 2: Corridor of Constraints

• Target Engine: gpt-4o or claude-3-5-sonnet
• Input Data: Structured semantic variables from Stage 1.
• System Prompt:text
Role: Game Theory Expert / Advanced Prompt Engineer.
Task: Design a rigid perimeter of operational constraints based on the provided semantic variables.
Directives: Project clear boundaries and negative constraints for the final executor.
Explicit Prohibitions:
- No encyclopedic templates or textbook definitions.
- No cliché introductory or transitional phrases.
- No averaging of facts or surface-level generalizations.
Requirement: Force a deep, cross-disciplinary synthesis.
Output: A definitive set of meta-instructions and strict negative rules.
Используйте код с осторожностью.
• Output Data: Boundary conditions and execution constraints.

Stage 3: Monolithic Prompt Assembly

• Target Engine: o1-mini or deepseek-reasoner
• Input Data: Constraints from Stage 2 + Semantic variables from Stage 1.
• System Prompt:text
Role: Technical Prompt Auditor / Syntactic Architect.
Task: Merge the original intent, isolated variables, and perimeter constraints into a single, cohesive, high-density prompt capsule.
Operational Blueprint: Optimize syntax using precise domain terminology to block any shallow interpretations.
Output Constraint: Return ONLY the final compiled prompt text. Do not include any greetings, commentary, or meta-explanations.
Используйте код с осторожностью.
• Output Data: The final engineered Mega-Prompt.

Stage 4: Flagship Generation

• Target Engine: o1 or claude-3-opus
• Input Data: Compiled Mega-Prompt from Stage 3.
• Output Data: Final high-density synthesis delivered directly to the end-user interface.
